SGVE — Sistema Gerenciador de Vagas de Estacionamento

Sistema de gerenciamento de vagas dentro de um estacionamento, feito em Python, com um sensor feito em Arduino para detectar a ocupação das vagas e os dados armazenados no Google Firebase.

Python Arduino Firebase
Acessar o projeto

Sobre o projeto

O SGVE nasceu como um projeto para resolver um problema comum em estacionamentos pequenos e médios: controlar manualmente quais vagas estão disponíveis. Um sensor conectado a um Arduino identifica se cada vaga está livre ou ocupada, e essa informação é enviada e armazenada no Firebase, para ser consultada em tempo real.

Principais funcionalidades

  • Leitura da ocupação de cada vaga em tempo real, através de sensores no Arduino.
  • Envio automático dos dados do sensor para o Google Firebase.
  • Processamento e consulta das informações das vagas feitos em Python.
  • Visualização de quais vagas estão livres ou ocupadas no momento.

Desafios e aprendizados

O principal desafio foi integrar o Arduino com o Firebase, garantindo que os dados fossem enviados de forma confiável e em tempo real. Além disso, foi necessário aprender a lidar com a comunicação entre hardware e software, bem como otimizar o código Python para processar as informações rapidamente. Aprendi muito sobre a importância de testes em ambientes reais, já que o comportamento do sensor pode variar dependendo das condições do estacionamento.
